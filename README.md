# An Explainable AI Framework for Phishing URL Detection and Threat Analysis using machine learning

## 🛡️ ThreatShield AI: Real-Time Phishing URL Detection Framework

ThreatShield AI is a machine learning-based web application that detects phishing URLs in real time. The system analyzes URL characteristics and classifies them as **Phishing** or **Legitimate** using a Random Forest model enhanced with Explainable AI and threat analysis techniques.

## 🚀 Features

- 🔍 Real-time phishing URL detection
- 📊 Feature optimization using Principal Component Analysis (PCA)
- 🌲 Random Forest-based classification
- ⚠️ Rule-based suspicious pattern detection
- 🏷️ Brand impersonation detection
- 📈 Threat visualization using Plotly
- 🧠 Explainable AI with SHAP
- 📉 Risk score and severity analysis
- 💻 User-friendly Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- SHAP
- Matplotlib
- Joblib

## ⚙️ Workflow

1. Collect phishing and legitimate URL datasets.
2. Perform data preprocessing.
3. Extract important features using PCA.
4. Classify URLs using Random Forest.
5. Detect suspicious patterns and brand impersonation.
6. Calculate risk scores and visualize threat information.
7. Generate explanations using SHAP.
8. Display prediction results with detailed analysis.

## 📊 Algorithms Used

- **Principal Component Analysis (PCA)** – Feature extraction and dimensionality reduction.
- **Random Forest** – URL classification.
- **SHAP (Explainable AI)** – Model interpretability.
